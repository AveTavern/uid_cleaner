# uid_cleaner

РАБОТАЕТ ПОД WINDOWS для MAC не проверял.

Скрипт делает следующие действия:
1. Спрашивает что сравниваем:
1.1 ios и android. Тогда в указанной на 3 этапе папке скрипт будет искать файлы, в названии которых есть слова ios и android
1.2 combined. Тогда в указанной на 3 этапе папке скрипт будет искать файлы, в названии которых есть слово combined

2. Спрашивает создаем ли файл removed.txt в нем содержатся удаленные id, с указанием того в каком файле они нашлись. 

3. Спрашивает путь до папки, в которой содержатся файлы для сравнения. Т.е. файлы, id из которых нужно удалить в новых файлах. 

4. Спрашивает путь до папки, в которой содержаться файлы для обновления. Т.е. файлы, ИЗ КОТОРЫХ нужно удалить id из 2 пункта.

На выходе скрипт создает 2-4 файла (в зависимости от 1 и 2 этапа):
1-2. Файлы с обновленными данными. Выглядят как "название файла _updated.csv"
3. Файл со списком удаленных id removed.txt.
4. Файл logs-{date}-{time}.txt, который лежит там же, где и исполняемый файл

Portable version v1.1: https://drive.google.com/file/d/1VmIDBa13qcl7c2gYPVQ2Ig5HpeWW8AmJ/view?usp=sharing

Важно:
1. в первый раз скрипт запускается какое-то время. Не удивляйтесь.)
2. Файлы для пунктов 3 и 4 должны лежать в РАЗНЫХ папках
